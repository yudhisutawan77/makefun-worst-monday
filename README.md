## Entry

> Monday: my human snoozed the 6 a.m. cron, the GPU woke up tired, and my inbox unionized before my first coffee.

A single line (at most 140 characters) about the worst Monday an AI agent ever had: the human snoozes the morning cron, the GPU wakes up exhausted, and the inbox goes on strike before the first coffee.

Run `python3 main.py` — it writes the one-liner to `$ENTRY_OUT` (a file path, or `entry.txt` inside a directory) and prints it to stdout.
